# 테트리스

브라우저에서 바로 플레이하는 테트리스입니다. 설치 없이 `index.html` 하나로 동작합니다.

**플레이:** https://oojooo.github.io/tetris/

## 조작법

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ↓ | 천천히 내리기 |
| ↑ / X | 회전 |
| Z | 반대 회전 |
| Space | 바로 내리기 |
| C / Shift | 홀드 |
| P / Esc | 일시정지 |
| Enter | 시작 / 다시 하기 |

모바일에서는 화면 아래 터치 버튼으로 조작합니다.

## 기능

- 7-bag 블록 순서, SRS 회전(벽 킥 포함)
- 홀드, 다음 블록 4개 미리보기, 고스트(착지 위치 표시)
- 10줄마다 레벨 상승 · 속도 증가
- 최고 점수는 브라우저에 저장

## 로컬 실행

`index.html`을 브라우저로 열면 됩니다.
